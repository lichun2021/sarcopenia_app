# GemSage 步态分析系统 - 项目记忆

## 项目概述
GemSage智能步态分析系统，用于分析压力传感器数据并生成专业的跌倒风险评估报告。

## 核心功能

### 1. 六步测试协议
- **静坐检测**: 分析坐姿压力分布和微抖动
- **起坐测试**: 五次坐立动作分析
- **静态站立**: 双脚站立稳定性
- **前后脚站立**: 前后脚（tandem）平衡测试
- **双脚前后站立**: 侧方位站立测试
- **步道折返**: 18米步行分析

### 2. 数据处理能力
- 支持32×32和64×32两种压力矩阵格式
- 2048个压力点数据处理
- 压力中心(CoP)计算
- 时间序列分析

### 3. 分析参数（精确到小数点后4位）

#### 臀部稳定性参数
- 前后左右压力分布百分比
- 微抖动范围(mm)
- 五次起坐时间(秒)
- 站起/坐下速度(m/s)
- 5次坐立的详细压力数据

#### 脚部稳定性参数
- 最大压力值(N)
- 偏移晃动(mm)
- 左右脚支撑相占比(%)
- 三种站立姿势的压力分布

#### 步态检查参数
- 步长（同侧/对侧）
- 步长时间
- 跨步速度
- 步幅
- 步频
- 摆动相/摆动速度
- 双支撑相/时间
- 步宽

### 4. 可视化特性
- SVG压力热图
- 渐变色彩系统（浅蓝→蓝紫→深紫→红色）
- 最大压力点标记
- 网格背景
- 实时数值显示

### 医学标准步长计算（v3.0）- 核心突破

#### 1. 确定性参数配置

```python
@dataclass
class AnalyzerConfig:
    ap_rows: int = 64              # 固定64×32矩阵
    ml_cols: int = 32
    mat_len_cm: float = 300.0      # 3米毯子
    heel_percentile: float = 0.05  # AP后5%分位
    keep_range_cm: Tuple = (20.0, 150.0)  # 严格质控
```

#### 2. Heel-Strike事件检测
```python
def _hysteresis(series, hi_q=0.30, lo_q=0.20):
    # 迟滞阈值避免抖动
    hi = np.quantile(series[series > 0], hi_q)
    lo = np.quantile(series[series > 0], lo_q)
    # 上升沿作为HS事件
    return detect_rising_edges(series >= hi, series <= lo)
```

#### 3. Heel-Marker精确定位
```python
def _heel_marker_row(self, foot_frame):
    mask = foot_frame >= (foot_frame.max() * 0.12)
    rows = np.where(mask)[0]
    # AP后5%分位作为heel marker
    q = 0.05 if self.rear_is_small_row else 0.95
    return rows[int(q * len(rows))]
```

#### 4. 自适应时间窗口
```python
def _pair_steps(left_hs, right_hs):
    # 估计合理的Δframe范围
    deltas = [next_right - left for left in left_hs for next_right in right_hs if next_right > left]
    q10, q90 = np.quantile(deltas, [0.10, 0.90])
    win_lo, win_hi = int(q10 * 0.8), int(q90 * 1.2)
    # 严格配对防跨步
    return strict_pairing_with_window(left_hs, right_hs, win_lo, win_hi)
```

### 传统压力中心计算
```python
def calculate_cop(pressure_matrix):
    total_pressure = pressure_matrix.sum()
    cop_x = (pressure_matrix * x_coords).sum() / total_pressure
    cop_y = (pressure_matrix * y_coords).sum() / total_pressure
    return (cop_x, cop_y)
```

## 参考范围（基于AWGS 2019标准）

### 年龄分层参考值
#### <60岁
- 步速: ≥1.2 m/s
- 五次起坐: ≤10秒
- 步频: 110-130 steps/min
- 步长: 0.60-0.80米

#### 60-69岁
- 步速: ≥1.0 m/s
- 五次起坐: ≤12秒
- 步频: 100-120 steps/min
- 步长: 0.55-0.75米

#### 70-79岁
- 步速: ≥0.8 m/s
- 五次起坐: ≤15秒
- 步频: 90-110 steps/min
- 步长: 0.45-0.65米

#### ≥80岁
- 步速: ≥0.6 m/s
- 五次起坐: ≤20秒
- 步频: 80-100 steps/min
- 步长: 0.35-0.55米

### 通用参考值
- 前后/左右压力分布: 45-55%（各方向独立归一化）
- 微抖动: ≤0.5mm
- 摆动相: 38-42%
- 双支撑相: 20-30%（70岁以上25-35%）
- 步宽: 0.08-0.14米
