# GemSage步态分析系统

一个专业的AI驱动步态分析和跌倒风险评估系统，能够处理压力传感器数据并生成详细的医疗分析报告。

## ✨ 系统特性

### 🔬 专业分析功能
- **多维度步态分析**: 支持6种标准化测试（静坐、起坐、站立、前后脚站立、侧位站立、行走）
- **压力中心计算**: 精确计算压力中心轨迹，支持小数点后4位精度
- **转身识别**: 智能检测行走过程中的转身动作和方向变化
- **左右脚互换处理**: 自动处理复杂步态场景中的足部识别
- **步距精确测量**: 基于压力点距离计算，无需依赖时间和步数

### 📊 数据处理能力
- **32x32压力网格**: 支持高分辨率压力传感器数据（实际支持64x32等变体）
- **实时压力分析**: 处理CSV格式的时序压力数据
- **多传感器集成**: 支持臀部垫和脚部垫的联合分析
- **数据完整性验证**: 自动检查和验证数据质量

### 📈 可视化与报告
- **专业医疗报告**: 基于标准HTML模板生成符合医疗规范的报告
- **多类型图表**: 压力热力图、轨迹图、时间序列图、3D表面图
- **参数范围对比**: 自动与标准参考范围进行对比分析
- **专家建议生成**: 基于分析结果自动生成康复建议

### 3. 数据格式要求

CSV文件需包含以下字段：
- `time`: 时间戳（浮点数）
- `max`: 最大压力值
- `timestamp`: 时间戳字符串
- `area`: 压力面积
- `press`: 总压力值
- `data`: 压力点数组字符串 `"[value1,value2,...]"`

## 📋 测试步骤说明

### 标准6步测试协议

1. **第1步-静坐检测**: 评估坐姿稳定性和微抖动
2. **第2步-起坐测试**: 分析5次起坐的动力学表现
3. **第3步-静态站立**: 评估双脚站立时的平衡能力
4. **第4步-前后脚站立**: 测试前后脚位置的平衡稳定性
5. **第5步-双脚前后站立**: 评估侧位站立的稳定性
6. **第6步-4.5米步道折返**: 综合步态和转身分析

## 🎯 核心算法特点

### 压力中心计算
```python
CoP_x = Σ(pressure_i × x_i) / Σ(pressure_i)
CoP_y = Σ(pressure_i × y_i) / Σ(pressure_i)
```

### 步距测量方法
- 基于压力中心轨迹的几何距离
- 自动校正转身后的坐标系变换
- 支持前进和后退方向的步长计算

### 转身检测算法
- 方向向量角度变化分析
- 滑动窗口累积角度阈值检测
- 自动识别左转和右转
